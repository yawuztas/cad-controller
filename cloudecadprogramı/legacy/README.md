# CloudeCAD Legacy Modülleri (Arşiv)

Bu dizindeki modüller CloudeCAD v1.x döneminde geliştirilmiş olan ayrık motorlardır:
- `superpose_motoru/`
- `topraklama_motoru/`
- `yukleme_cetveli/`
- `zayif_akim/`

Bu ayrık modüller yerine CloudeCAD v2.0 ile birlikte tüm disiplinleri tek çatı altında toplayan, 
daha hızlı, hatasız ve uzamsal indekslemeli evrensel motorlar devreye alınmıştır:
- `cloudecadprogramı/common/dxf_converter.py`
- `cloudecadprogramı/common/universal_cad_reader.py`
- `cloudecadprogramı/common/station_audit_engine.py`

Bu dizindeki kodlar geriye dönük uyumluluk ve algoritma referansı amacıyla arşivlenmiştir.
